Display routines
-----------------
The :code:`makutu/display` folder contains three main scripts that you can use to visualize easily the data generated by the workflows.


.. rubric:: Seismic traces

To visualize seismic traces in :code:`.H` or :code:`.segy/.sgy` format, 

.. code-block:: bash

    usage: showSeismicTraces.py [-h] [--dir DIR] [--vmin VMIN] [--vmax VMAX] [--nf NF] [files [files ...]]

    Basic seismic traces display. Only .H and .sgy/.segy files handled

    positional arguments:
    files                 Filenames

    optional arguments:
    -h, --help            show this help message and exit
    --dir DIR             File directory. Should be common to all files
    --vmin VMIN           Bound min
    --vmax VMAX           Bound max
    --nf NF, --norm_factor NF
                            Normalisation factor
   

An example of command line:

.. code-block:: bash

    python3 showSeismicTraces.py seismo_00001.H seismo_00002.H --dir=../seismoTraces --nf=100



.. rubric::  Velocity model

This script allows to visualize the velocity models generated in HDF5 format by the FWI workflow.


.. code-block:: bash

    usage: showVelocityModel.py [-h] [--dir DIR] [--n N N N] [--extent EXTENT EXTENT EXTENT EXTENT] [--axis AXIS] [--index INDEX]
                            [--vmodel VMODEL] [--fname FKEY] [--vmin VMIN] [--vmax VMAX] [--nf NF] [--diff]
                            [files [files ...]]

    HDF5 velocity model display

    positional arguments:
    files                 Filenames. If >1, should have the same shape and extent

    optional arguments:
    -h, --help            show this help message and exit
    --dir DIR             File directory. Should be common to all files
    --n N N N             Shape of the model
    --extent EXTENT EXTENT EXTENT EXTENT
                            Extent of the graph
    --axis AXIS, --slice_axis AXIS
                            Slice axis
    --index INDEX, --slice_index INDEX
                            Slice index
    --vmodel VMODEL       Model, 'c', '1/c' or '1/c2'
    --fname FKEY          Name of the field in the HDF5 file. Default is `velocity`
    --vmin VMIN           Graph min bound value
    --vmax VMAX           Graph max bound value
    --nf NF, --norm_factor NF
                            Graph normalization factor
    --diff                Compute and display difference between two velocity models
    

An example of command line:

.. code-block:: bash

    python3 showVelocityModel.py --dir=FWI/velocityModel velocityModel1.hdf5 velocityModel2.hdf5 --vmodel="1/c2"



.. rubric:: Full gradient

.. code-block:: bash

    usage: showFullGradient.py [-h] [--dir DIR] [--n N N N] [--extent EXTENT EXTENT EXTENT EXTENT] [--axis AXIS] [--index INDEX]
                            [--fname FKEY] [--vmin VMIN] [--vmax VMAX] [--nf NF] [--diff]
                            [files [files ...]]

    HDF5 full gradient display

    positional arguments:
    files                 Filenames. If >1, should have the same shape and extent

    optional arguments:
    -h, --help            show this help message and exit
    --dir DIR             File directory. Should be common to all files
    --n N N N             Shape of the model. Default is (127,96,122)
    --extent EXTENT EXTENT EXTENT EXTENT
                            Extent of the graph. Default is None
    --axis AXIS, --slice_axis AXIS
                            Slice axis
    --index INDEX, --slice_index INDEX
                            Slice index
    --fname FKEY          Name of the field in the HDF5 file. Default is `fullGradient`
    --vmin VMIN           Graph normalization min bound
    --vmax VMAX           Graph normalization max bound
    --nf NF, --norm_factor NF
                            Graph normalization factor
    --diff                Compute and display difference between two fields



.. code-block:: bash

    python3 showFullGradient.py FWI/fullGradient.hdf5 --n 127 96 122 --extent 0 2520 1220 0 --axis y --index 50
